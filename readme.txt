An extension for Elementor/Elementor Pro which adds additional functionality for accessibility.

== Description ==

CoreA11Y For Elementor is an add-on for Elementor that adds additional settings inside of Elementor to help fix accessibility issues.


**Site Settings**

Inside the global site settings, you can set global styles for `:focus-visible` states in the following sections:

*   Buttons
*   Form Fields
*   Typography

**Widgets**

And inside individual widgets, you can override the global `:focus-visible` settings when needed, as well as adjust for other widgets not in the global settings.

* Button
* Call to Action
* Form
* Testimonial Carousel

**Additional Information**

This plugin will not fix every and all accesibility issue your Elementor site may have - it will only help you adjust the features mentioned above.
